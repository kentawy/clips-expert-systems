# Експертні системи на базі CLIPS

Репозиторій містить результати розробки баз знань та правил у середовищі CLIPS в рамках дисципліни «Інтелектуальні інформаційні технології».

## Автор
- Студент: Дмитренко Богдан
- Група: ІН-33-4

## Структура репозиторію
- `Lab1/` – операції з фактами (assert, retract, facts);
- `Lab2/` – створення шаблонів (deftemplate) та впорядковані факти;
- `Lab3/` – формування бази правил (defrule) експертної системи;
- `Lab4/` – створення та використання функцій (deffunction);
- `Lab5/` – дерева рішень та логічне виведення;
- `README.md` – опис проєкту.

## Висновки
Під час виконання лабораторної роботи було освоєно базові принципи роботи з системою контролю версій Git та сервісом GitHub. Набуто практичних навичок створення репозиторіїв, організації структури папок для навчальних проєктів, завантаження файлів програмного коду `.clp` та оформлення документації за допомогою мови розмітки Markdown у файлі README.md. Головною складністю було правильне створення вкладених папок через веб-інтерфейс GitHub, що вирішувалося шляхом створення файлів із косим слешем у назві. Отримані навички забезпечують надійне зберігання та структурування результатів розробки програмних проєктів.
